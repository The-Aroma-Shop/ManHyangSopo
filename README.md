## ✅ 구현된 기능

### 페이지 구조 (상단 → 하단 스크롤)
1. **漫香小舖 로더** — 꽃모양 SVG 애니메이션 + 로딩 바
2. **고정 헤더 네비게이션** — 향수/스킨케어/라이프케어/브랜드스토리 + 검색·계정·장바구니 아이콘
3. **히어로 섹션** — 전체화면 배너, 한자 타이포, 전통·자연·장인 뱃지, Made in Korea 스탬프
4. **원료 스포트라이트** — 솔잎·편백·생강·쑥·매화 등 천연 원료 그리드
5. **만향소포 철학** — 이미지 + 텍스트 2단 레이아웃, 브랜드 핵심 가치
6. **제품 컬렉션** — 4열 그리드, 탭 필터 (ALL / 에센셜오일 / 향수&미스트 / 디퓨저 / 스킨케어)
7. **브랜드스토리** — 배경 오버레이 + 카운트업 통계 수치
8. **뉴스레터 구독** — 이메일 입력 + 구독하기
9. **올리브 그린 푸터** — 4열 구조 + SNS 링크 + 漫香小舖 워터마크

- ✅ 스크롤 시 헤더 그림자 효과
- ✅ 모바일 햄버거 메뉴
